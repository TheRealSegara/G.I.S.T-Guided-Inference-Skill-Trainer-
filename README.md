# G.I.S.T-Guided-Inference-Skill-Trainer-
G.I.ST (Guided Inference Skill Trainer) is an AI-powered reading assessment tool built for Malaysian primary school ESL students. Rather than testing vocabulary in isolation, G.I.ST asks students to to work out unfamiliar words directly from context, guided step by step by one of eight animal coach personas, never handed the answer outright.
